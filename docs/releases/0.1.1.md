MCEdge 0.1.1 adds new element types, faster folder work in Resources and narrow-window layouts.

**New elements**
- **Bubbles:** speech and icon bubbles above players. They are designed like a GUI, previewed in the editor and shown with the "Show bubble" block.
- **Radial menus:** an independent element bound to a key. Icons can come from textures or from image folders under `config/<modid>/` that are read when the server starts or on `/<modid> reload`.
- **Seatable blocks:** set seat and lying spots by clicking or dragging in the 3D preview, with the number of seats and the sitting height. Furniture made of several blocks, such as an L-shaped sofa, can be one multi-block.

**Animation**
- **Show and hide timing:** bubbles and the radial menu share appear and disappear effects (fade, scale, slide), each with its own duration and easing, plus how long the element stays on screen. The bubble editor has a timeline.
- **Animated textures:** block, item and GUI textures can loop, stop on the last frame or play back and forth. GUI images can restart their animation from a procedure.

**Editor**
- **Resources folders:** every Resources tab has nested folders that can be renamed, deleted and moved, with visible folder buttons and multi-select move.
- **Deleting elements:** deleting an element lists and removes what depends on it. Problems reports translation keys no element uses.
- **Narrow windows:** the menu, title bar, find bar and Agents panel fit narrow windows.
- **Status bar:** toggles panels and opens the project folder.
- **Help:** "Report a bug" opens a GitHub issue.
- **Auto-update:** installed copies now show update progress.

**Procedures**
- Loop over every player on the server, find a player by name, and react to GUI slot changes.
- Warns when a client-side store keeps text the server translated.

**MCP**
- New tools: `run_scenario`, `tick_profile` and `unused_translation_keys`. `texture_folders` works on every resource kind.

**Publishing**
- **Modrinth and CurseForge:** File > Export mod jar can publish. Every chosen engine is built and its server must start with the mod; only then is the version tagged and each jar uploaded with its game version and loader. A failed step uploads nothing. Tokens are set in Preferences > Publishing, projects in Mod settings.

**AI assistant**
- **In the Agents panel:** chat with an AI that edits the project with the same tools outside agents use, on your own Anthropic key or an OpenAI-compatible server such as LM Studio (Preferences > AI). Ctrl+Shift+A opens it. Each reply can be undone.

**Code mode**
- **Java completion:** the Java editor completes from the mod's real Minecraft classpath (Eclipse JDT language server, downloaded on first use), offers the mod's own ids inside strings, and warns when client-only API is used in common or server code.

**Testing**
- **Scenarios:** a Scenarios tab runs a scenario (place a block, use it, check the result) on a real server and shows each step's result. Reload data applies changes to a running server without a restart.

**Smaller changes**
- The New element menu groups types in folders with a preview on hover and closes on a click outside.
- The Git view's diff area can be resized.
- Preferences scrolls inside the window, and its sections collapse.

The exe files are not code-signed, so Windows SmartScreen may warn on first start (More info > Run anyway).
