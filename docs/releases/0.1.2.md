MCEdge 0.1.2 has a new layout, a faster editor and a guided start for new modders.

**New layout**
- **Dock layout:** the GUI and texture editors have the canvas in the middle, tools on the left and an inspector on the right. The other screens (grid, element editor, tags, variables, localization, settings, git, problems) use the same frame.
- **Editor tabs:** open elements stay as tabs. The bottom panel can be resized and remembers its height.
- **One size system:** buttons and dialogs share a few fixed sizes, so screens line up.

**Speed**
- Opening projects, GUIs and the Resources tab is faster. Resources thumbnails load as they scroll into view.
- The 3D preview no longer leaks memory when closed. The app's renderer is about half its former size.

**Getting started**
- **First-run setup:** choose your level; Simple mode hides advanced fields, Advanced shows everything.
- **First-mod tour:** an interactive tour builds a first mod step by step.
- **Template gallery:** start a project from verified starters.
- **Plain-language errors:** build and Java errors are explained in plain words with what to do.
- **Learn by hand:** each AI action also shows how to do it yourself.

**Accessibility**
- Preferences > Accessibility: UI scale, high contrast, a colour-blind-safe palette and reduced motion.
- Every screen works with the keyboard alone and with a screen reader.
- Preferences > Performance for weak computers: turn off previews and 3D rendering, limit memory; the first start suggests settings for the machine.
- Community translations: a language file dropped into `config/ui-strings` appears in the language picker.

**GUI and textures**
- GUI images have opacity and a colour filter. Image and toggle buttons no longer stay lit after a click.
- GUI slots can filter what is placed in them; shift-click sends a stack to its matching slots first.
- The GUI editor's text preview matches the game.
- Textures: trim the canvas to the drawing.

**Procedures**
- Compare two item stacks including their components.
- Walk an entity to a position, run a work procedure as an AI goal, keep data on each entity, swing a mob's arm and set its held item.
- Read a structure template block by block.
- A hurt procedure that returns false cancels the damage.
- `java_code` blocks can be limited to one loader.
- Fixed: cancelling one event no longer cancels a nested one; variable sync no longer disconnects clients; old map variables load with their values.

**MCP**
- Pixel art tools: preview, palette, fills, frames and atlases.
- GUI design tools: layout checks, arranging widgets and a design guide.

**Smaller changes**
- Settings are reachable from the top menu and the title bar.
- The status bar shows only an icon when there are no problems; clicking it toggles the bottom panel.
- Child processes open no console windows, and agents stop when the app is closed.

The exe files are not code-signed, so Windows SmartScreen may warn on first start (More info > Run anyway).
